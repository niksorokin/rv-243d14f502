FAQ

Questions, answered.

Can our team install it without you?
Yes. One container stack, an install README and an acceptance script that verifies every stage. We join the install call if you want us there.
Does any screenshot or video leave our perimeter?
Not to Silow — ever. On your own or cloud GPUs, nothing leaves at all. With an inference provider, data is processed under zero data retention.
How is PHI handled? Workers’ comp files?
Redaction runs first and masks PII and PHI before anything is analysed or stored. We already run this on-prem in a HIPAA claims environment.
What hardware do we need?
A Linux server with Docker for the platform. GPUs only if you run the models in-house — we size them with your infrastructure team.
Which models?
Open-source models on your GPUs, or frontier models from OpenAI, Anthropic or Gemini under ZDR. You choose per stage.
Who sees the data?
Only people you authorise, through your SSO. Reports show workflows, not individual scorecards. Every access is logged.
Is it productivity monitoring?
No. No keystrokes, no message content, no rankings, no human playback of anyone’s day.
Remote desktops and VDI?
Supported. If the work happens in a remote session, we test that exact setup before rollout.
What does it run on?
macOS, Windows and Linux. One-minute install, 1–2% CPU. No connectors, no workflow changes.
